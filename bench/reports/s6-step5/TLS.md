# S6 Step 5 TLS sample

Seed 20261105; 30 distinct companies sampled uniformly from 206 companies with saved HTTPS transport failures. The first failed HTTPS request per company was retried verbatim. This samples recorded transport failures, including failures later recovered by another candidate; it is not a sample of all 442 companies in the broad loss bucket.

Historical request logs contain class names but omit exception messages. Their exact historical messages cannot be reconstructed. The default retry captures contemporary exact exception classes, messages, repr, and complete cause/context chains; the same is recorded for truststore and explicit certifi. curl exit codes and exact stderr are retained. All 120 results are in `tls/sample30.json`.

Windows, Python 3.12.15, truststore 0.10.5, certifi 2026.07.22. curl 8.21.0 Windows, Schannel; direct connections; no insecure option. Verified TLS throughout; 8 second whole-request cap, no redirects, no credentials/search, no proxy. Python uses the production public-IP transport; curl pins the first vetted public IPv4 when available. Arm order rotates to reduce timing bias. Responses are not ownership proof and are never published.
